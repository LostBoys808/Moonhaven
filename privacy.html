2. Current prototype

The downloadable Moonhaven website is currently a static front-end prototype. It has no Moonhaven account system, Discord OAuth login, connected bot, or cloud database. Its interactive demo data is held in page memory and may disappear when the page is refreshed or closed. Do not use this prototype for real sensitive information.

If the site is published through a hosting provider, that provider may process technical information such as IP addresses, request timestamps, and server/security logs according to its own terms and privacy policy. Identify the actual provider and link to its policy before launch.

3. Planned bot and future data processing

Future Moonhaven features may allow users to create headmate profiles, aliases, pronouns, descriptions, avatars, tags, fronting records, journal entries, preferences, and import/export files. Some of this may reveal sensitive information. Do not treat these planned features as already active. Before enabling them, the operator must document exactly what data is collected, the purpose and legal basis for each use, where it is stored, who can access it, how long it is retained, and how users can delete or export it.

If a future version connects to Discord, it may process Discord user IDs, server IDs, command interactions, and information users intentionally submit.
