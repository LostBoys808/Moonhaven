What is Moonhaven?

A soft, customizable Discord companion concept for plural systems and people exploring system-related organization. Moonhaven aims to make it easier to keep track of profiles, fronting check-ins, notes, boundaries, and personal preferences — without telling anyone what their experience should look like.

Current status: This website is a front-end prototype. The Discord bot, live slash commands, accounts, cloud storage, and permissions are not connected yet. The command list below is a planned command blueprint, not a list of working commands.

🌷 Made to be flexible

Create customizable headmate profiles with names, display names, pronouns, colors, avatars, birthdays, aliases, proxy tags, groups, and extra fields. Keep things simple or make each profile your own.

🫧 Your boundaries matter

Moonhaven is intended to respect different language, identities, and ways of describing experiences. No one should have to share private information to use basic features.

📖 Personal organization

Optional fronting check-ins, journal entries, reminders, and personal preferences can help keep useful information together. Tracking anything is optional.

🔄 Bring your data

The website prototype includes best-effort member-profile import/export for JSON backups. A future bot integration should explain exactly what transfers and what does not.

Our principles ♡

Consent before sharing

Private by default should be the goal for sensitive information, with clear controls before anything is shared.

No one-size-fits-all assumptions

Plural experiences differ. Moonhaven should let users choose their own terms and workflows.

Clear and honest privacy

The live bot must explain what is stored, where it is stored, who can access it, and how to delete or export it.

Accessible and gentle

Clear instructions, predictable commands, and helpful error messages — without pressure to fill every field.

Import & export

Move member data between Moonhaven and a PluralKit backup. Review the notes below before importing.

Compatibility note: PluralKit's pk;export creates a JSON backup containing system, member, and switch information. This tool imports common PluralKit member fields and exports a PluralKit-shaped JSON backup. Moonhaven-only custom fields are preserved in Moonhaven JSON exports, but cannot be represented by PluralKit's format. PluralKit export guide ↗

Import backup

📥

Choose a JSON file exported from PluralKit (`pk;export`) or Moonhaven. Imported profiles are added to the current list; duplicates are not automatically merged.

Export backup

📤

Download a backup to keep a copy. PluralKit JSON is best for member fields shared with PluralKit; Moonhaven JSON keeps custom fields too.

This only downloads a file; it does not upload data to PluralKit or change your PluralKit system.

What may transfer?

Usually transferable

Name, display name, pronouns, description, color, birthday, avatar URL, aliases, proxy tags, and some standard member settings.

Moonhaven-only fields

Custom labels, extra fields, profile emoji, local notes, and UI preferences are kept in Moonhaven JSON. They won't become native PluralKit fields.

Switch history and system metadata

This first version focuses on member profiles. Switch history and every system/group field are not fully round-tripped yet. Review an export before relying on it as your only backup.

Settings

Local preferences for this prototype.

Theme

Moonhaven's current theme is dreamy lavender, pastel pink, and cloud white. Additional themes can be added later.

Data storage

This version stores its working data in the current browser session only. It does not use an account or cloud database.

Clear demo data

Permanently remove all profiles, notes, and check-ins from the current page session.
